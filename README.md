# みんなの在庫帳

グループで同じ在庫を見て、数の増減をリアルタイムに共有する在庫管理アプリです。
Claude のアカウントがない人でも、URL を開くだけで使えます。

- アプリ本体：`app/`（GitHub Pages で公開）
- データ：Firebase（Cloud Firestore）に保存。変更は全員の画面へすぐ反映
- Firestore のルール：`firestore.rules`
- 公開の自動化：`.github/workflows/pages.yml`（`app/` を変更して push すると自動で公開）

## はじめに一度だけやること

### 1. Firebase のプロジェクトを作る
1. https://console.firebase.google.com を開き、Google アカウントでログイン
2. 「プロジェクトを作成」→ 名前（例：zaiko）→ Google アナリティクスはオフで OK → 作成

### 2. データベース（Firestore）を作る
1. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
2. ロケーションは **asia-northeast1（東京）**
3. 「**本番環境モード**」で開始

### 3. ルールを貼り付ける
1. Firestore の画面上部の「ルール」タブを開く
2. 中身を全部消して、このリポジトリの `firestore.rules` の内容を貼り付け →「公開」

### 4. ウェブアプリを登録して設定を取り出す
1. 左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」でウェブ（`</>`）のアイコン
2. ニックネーム（例：zaiko-web）→「アプリを登録」（Firebase Hosting のチェックは不要）
3. 表示された `firebaseConfig = { ... }` の中身を `app/firebase-config.js` の `window.FIREBASE_CONFIG` に入れる
   （この値はパスワードではなく、ウェブアプリでは公開して使う前提のものです）

### 5. GitHub Pages を有効にする
リポジトリの Settings → Pages → Build and deployment の Source を **GitHub Actions** にする。

公開後の URL：https://toyohide8119-ui.github.io/-/

## 使い方

### 在庫一覧（1つ目のタブ）
- 大分類ボタン（すべて／DR／MP…）で絞り込み。品名の【 】の前の文字が大分類になります
- ＋／−で1つずつ増減。変更は全員の画面にすぐ反映
- 数字をタップするとテンキーが出る。数を打って「決定」→【出庫】（減る）【入庫】（増える）【交換】【廃棄】（減る・理由が必要）から選ぶ。【数を直す】で在庫数をそのまま合わせることもできる（棚卸し用）
- 交換・廃棄の理由は一度使うとボタンで選べる。今日の動きに「交換：袋破れ」のように表示される
- 品名をタップすると詳細（場所・更新時刻・更新した人・編集/削除）
- 品目は決まった順（DR20㎏→DR30㎏→MP5㎏→MP10㎏→MP20㎏→MP20㎏13㎜→MP20㎏白黒）で並びます。在庫切れ・残りわずかの品目は上に出ます。一覧の下の「並び順を変える」で▲▼で並べ替えできます（全員に反映）
- 「要補充だけ」で、在庫切れ・残りわずかの品目だけを表示
- 予定がある品目には「予定後 ○袋（〜日付）」を表示

### 増減の記録（2つ目のタブ）
- 7日／30日／90日の、日ごとの増えた・減ったのグラフと表
- 品目を選ぶと在庫数の推移グラフ
- 「今日の動き」：1日の中の変更を時刻・増減・変更後の数・変えた人つきで表示（日付は切り替え可）

### 予定（3つ目のタブ）
- 出庫予約（減る）と製造予定（増える）を日付つきで登録
- 品目ごとに、予定後の見込み在庫を日付順に表示（目安以下はオレンジ、不足は赤）
- 出庫予約の「現場名・相手先」は一度入力すると全員共通のリストに保存されます。エクセルのリストのように ▼ を押すと、あいうえお順の一覧から選べます（直接入力も可。入力中は一致する名前の候補が出ます。「整理」で不要な名前をリストから消せます）
- 漢字などを含む名前には「よみ（ひらがな）」を入れられ、よみの順に並びます。かな漢字変換で入力すると、よみは自動で入ります。あとから「整理」→「よみを入れる」でも直せます
- 「最近の済み・取消」と、増減の記録の「今日の動き」に、現場名・相手先も表示されます
- 登録した予定は「直す」で、日付・品目・数量・種類・現場名をあとから修正できます
- 当日に「出庫済み／製造済み」を押すと在庫が自動で増減。中止は「取消」

### 名前
- 初めて開いた端末では名前の入力画面が出ます（ニックネーム可）。名前を保存しないと数を変えられません
- 名前は端末ごと（iPhone は Safari とホーム画面のアプリで別々）

## 注意
- 合言葉なしのため、URL を知っている人は誰でも見て変更できます。URL はグループ内だけで共有してください
- 少人数での利用なら、Firebase の無料枠（Spark プラン）に収まる見込みです
- 画面右下の「Ver.」で最新の画面か確認できます。古い番号のままなら、アプリを完全に閉じて開き直してください

## バージョンの付け方（画面右下の Ver.）
- Firebase のルールの貼り替えが必要な変更 → 整数を上げる（例：Ver.26 → Ver.27）
- それ以外の変更 → 小数点以下を上げる（例：Ver.26 → Ver.26.1 → Ver.26.2 … → Ver.26.10）
- 整数を上げたら小数点以下は付けない（例：Ver.26.3 → Ver.27）
- 版の表示は `app/index.html` の `<p class="ver">`、あわせて `app/sw.js` の `CACHE` 名も変える
