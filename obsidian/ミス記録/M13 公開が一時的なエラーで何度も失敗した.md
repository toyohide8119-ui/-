# M13 公開が一時的なエラーで何度も失敗した

**プロジェクト**：[[みんなの在庫帳]]　**一覧**：[[ミス一覧]]

## 何が起きたか
GitHub Pages の公開が「No artifacts named github-pages」で何度も失敗し、毎回やり直しが必要だった。

## 原因
作成（アップロード）と公開を1つの job で続けて行っていて、アップロードの完了が公開側にまだ伝わっていないことがあった。

## 直し方
作成（build）と公開（deploy）を別の job に分け、作成が終わってから公開するようにした。その後は1回で成功している。

## 二度と起こさないために
- Pages の公開は build と deploy を分ける（[[公開と確認の手順]]）
