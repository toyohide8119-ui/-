# M14 渡したZIPのファイル名が文字化けした

**プロジェクト**：[[みんなの在庫帳]]　**一覧**：[[ミス一覧]]

## 何が起きたか
Obsidian のノートを ZIP にして渡したら、展開したときに日本語のファイル名が文字化けして、中身が分からなかった。

## ユーザーの言葉
「zipファイルの中身が文字化けしててよく分からない」

## 原因
Linux の `zip` コマンドで作ったため、ファイル名に「UTF-8 で書いてある」という印（フラグ）が付いていなかった。パソコン側が別の文字コードとして読んだ。

## 直し方
Python の `zipfile` で作り直した（日本語の名前には自動で UTF-8 の印が付く）。全ファイルに印が付いていることと、展開して名前が正しいことを確かめてから渡した。

## 二度と起こさないために
- [[公開と確認の手順]] の「ファイルを渡すとき」に項目を足した
