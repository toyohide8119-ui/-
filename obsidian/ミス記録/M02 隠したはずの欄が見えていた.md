# M02 隠したはずの欄が見えていた

**プロジェクト**：[[みんなの在庫帳]]　**一覧**：[[ミス一覧]]

## 何が起きたか
`hidden` を付けて隠したはずの欄が、画面に出ていた。

## 原因
CSS で `display: flex` などを指定した要素は、HTML の `hidden` より CSS が優先され、隠れなくなる。

## 直し方
`[hidden] { display: none !important; }` を追加した。

## 二度と起こさないために
- 最初から必ず `[hidden]{display:none!important}` を入れる（[[表示ミス防止チェックリスト]] 5）
