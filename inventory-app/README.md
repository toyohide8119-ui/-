# みんなの在庫帳

グループで同じ在庫をリアルタイムに管理し、補充が必要な品目をLINEに送れる在庫アプリです。
claude.ai のアーティファクトとして公開しています（共有データは claude.ai 側のデータベースに保存）。

- 品目の追加・編集・削除、＋/−ボタンで数量を増減
- 「残りわずか」の目安数を品目ごとに設定、在庫切れ・残りわずかを色で表示
- 検索・カテゴリ絞り込み
- 「LINEで送る」：補充が必要なもの／全品目の一覧文面を作ってLINEで共有

`inventory.html` はアーティファクト用のページ本体です（単体でブラウザで開くと共有データには接続できません）。
